# organiza.

> Repositório: `organiza`

Um painel de tarefas simples, leve e agradável para organizar o dia. Este projeto foi criado com React e tem foco em uma experiência clara, responsiva e sem dependências visuais externas.

## Funcionalidades

- Adicionar, concluir e excluir tarefas
- Filtros para visualizar todas, pendentes ou concluídas
- Resumo com tarefas pendentes, concluídas e percentual de progresso
- Persistência automática no `localStorage`
- Layout responsivo para celular e desktop

## Executar localmente

```bash
npm install
npm start
```

Para gerar uma versão de produção:

```bash
npm run build
```

## Tecnologias

- React
- Create React App
- CSS responsivo
- Jest + React Testing Library
